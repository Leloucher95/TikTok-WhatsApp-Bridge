02 / Envoyer dans une discussion

Le dernier destinataire est mémorisé dans ce navigateur. L'envoi automatique est facultatif et reste désactivé par défaut.

Choisis une discussion pour activer ce mode.

Mode d'emploi
  1. Scanne le QR code affiché dans le terminal (WhatsApp mobile → Appareils connectés).
  2. Sur TikTok Web, ouvre le chat où se trouve le sticker envoyé depuis le téléphone.
  3. Survole le sticker et clique sur « ↗ WhatsApp ». Le lien détecté remplira automatiquement le champ ci-dessus ; clique sur « Importer le sticker ».
  4. Choisis une discussion ; elle sera conservée pour les prochaines utilisations dans ce navigateur. Pour l'envoi en un clic depuis TikTok, coche « Envoi direct au dernier contact » et valide une seule fois son activation.
  5. Avec l'envoi direct activé, le clic sur ↗ WhatsApp ouvre le Bridge et lance import + envoi automatiquement. Sans ce mode, importe le sticker et confirme l'envoi comme auparavant.
La conversion s'effectue localement. Un client WhatsApp non officiel est utilisé : il peut cesser de fonctionner après une mise à jour et comporte un risque pour le compte.
